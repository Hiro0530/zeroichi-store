1. デジタル化・AI導入補助金2026(旧IT導入補助金)通常枠 6次締切分

  • 実施: 国(中小企業基盤整備機構)|対象地域: 全国
  • 受付: 3/30(月) 10:00〜10/30(金) 17:00(交付決定は12/10(予定)。7次以降の日程は公式スケジュールページで確認)
  • もらえる額: 補助率1/2以内(最低賃金近くで雇う従業員が一定割合以上なら2/3以内)。補助額5万円以上150万円未満(1プロセス以上)、150万〜450万円以下(4プロセス以上)
  • 対象になる人: 中小企業・小規模事業者等。登録されたIT導入支援事業者と組んで、登録済みのITツールを導入する事業
  • 飲食店に関係する理由: 予約管理・POSレジ・会計・勤怠などのクラウドサービス導入が対象になりうる

申請の順序

  1. GビズIDプライムを取得(発行まで、おおむね2週間)
  2. SECURITY ACTION(★一つ星か★★二つ星)を自己宣言(ID発行まで、おおむね2〜3日)
  3. IT導入支援事業者と、導入するITツールを選ぶ(公式サイトの「ITツール検索」)
  4. 支援事業者から『申請マイページ』の招待を受け、基本情報と書類を入力。支援事業者がツール情報・計画値を入力
  5. 内容を最終確認し、宣誓して事務局へ提出 → 交付決定の後に契約・導入

用意する書類(公式ページの記載より)

  • GビズIDプライム
  • SECURITY ACTIONの宣言済アカウントID
  • 交付申請に必要な添付書類(申請マイページで指示されるもの。公募要領で確認)

よくある不備・落とし穴

  • 今からGビズIDを取る場合、6次(10/30)には間に合いません。次の締切回を狙ってください
  • 契約・導入は交付決定の通知を受けてから(公式の申請フロー STEP05)
  • 締切の前日・当日はコールセンターが大変混み合うと公式に案内されています

2. 観光関連事業者のDX・経営力強化支援事業補助金(令和8年度 第2回募集)

  • 実施: 東京観光財団(東京都の事業)|対象地域: 東京都
  • 受付: 10/19(月)〜11/30(月) 23:59(公式は締切の1週間〜10日前の申請をすすめている)
  • もらえる額: 補助率2/3(賃上げ計画を達成した場合3/4)。上限3,000万円
  • 対象になる人: 都内で宿泊業・飲食業・小売業・旅行業などを営む中小企業者・個人事業主(観光関連事業者)
  • 飲食店に関係する理由: 外国人客を含む観光客を受け入れる飲食店のDX・新サービス開発が対象になりうる

申請の順序

  1. 募集要領・交付要綱を読む(jGrantsの制度ページに掲載)
  2. 中小企業診断士の資格を持つ専門家による経営診断・助言を受け、優先して解決すべき課題を決める(この事業の前提)
  3. その課題に取り組むための経費で申請(書類に不備があると受け付けられない)

用意する書類(公式ページの記載より)

よくある不備・落とし穴

  • すでに決まっている取組をそのまま申請できる事業ではない(専門家の診断が前提)
  • 締切間際の申請で修正が間に合わず、受け付けられない例が増えていると公式が注意

相談先: 東京観光財団 観光産業振興部 観光産業振興課 03-5579-8873

  • 対象になる人: 都内の中小企業者等(会社・個人事業主・中小企業団体)
  • 飲食店に関係する理由: 予約・顧客管理・会計などのクラウドツール導入に使える。スマートレジ等の専用機器は条件つきで対象(レンタルは対象外)

  1. GビズIDプライムを取得(審査に原則2週間程度)
  2. 募集要項と『申請時添付書類例』を読み、導入するツールの見積りを取る
  3. Jグランツと専用フォームで電子申請
  4. 採択・交付決定の後に導入(助成対象期間は2年間)→ 実績報告

用意する書類(公式ページの記載より)

  • PC・タブレットなどのハード機器や、表計算・文書作成などの汎用ソフトは対象外
  • 申請は事業者自身(または法令上代行が認められる士業)のみ。第三者のなりすまし申請・『代行します』『キャッシュバック』の勧誘に注意と公式に警告
  • 公社は特定の製品・ベンダーを認定していない

4. 受動喫煙防止対策助成金(令和8年度)

  • 実施: 国(厚生労働省・都道府県労働局)|対象地域: 全国
  • 受付: 10/1(木)〜1/31(日) 23:59(申請額が予算に達した場合、期日より前に締め切る予定と公式に明記)
  • もらえる額: 喫煙専用室等の設置に係る工費・設備費などの2/3(主たる業種が飲食店以外は1/2)。上限100万円
  • 対象になる人: 既存特定飲食提供施設(2020年4月1日時点で営業していた、資本金5,000万円以下・客席面積100㎡以下の飲食店など)を営む中小企業事業主で、労災保険の適用事業主
  • 飲食店に関係する理由: 飲食店が対象の中心になっている助成金

申請の順序

  1. 所在地の都道府県労働局(労働基準部 健康安全課または健康課)に事前相談(公式が推奨)
  2. 工事の着工前に『受動喫煙防止対策助成金交付申請書』を労働局へ提出
  3. 交付決定を受けてから契約・工事
  4. 工事完了後に支給申請(手順は手引きで確認)

用意する書類(公式ページの記載より)

  • 交付申請書と添付書類(一覧は厚労省『受動喫煙防止対策助成金の手引き』(2026年8月13日改正)に記載)
  • テナント・貸しビルの場合は施設管理者の承諾(公式Q&Aより)

よくある不備・落とし穴

  • 工事の前に申請が必要。交付決定前の契約・支払いにも事前の手続きが要る
  • 書類がそろい不備がない状態で初めて『受理』。提出しただけでは受理にならない
  • 必要以上の性能・高価な材料は減額の対象。面積あたりの上限額もある
  • 業者が実質的に申請書を作り、申請者が内容を理解していなかった事例が問題になったと公式に注意あり

相談先: 事業場の所在地の都道府県労働局 労働基準部 健康安全課(又は健康課)

6. 小規模事業者持続化補助金〈一般型 通常枠〉第20回

  • 実施: 国(商工会議所地区・商工会地区それぞれの事務局)|対象地域: 全国
  • 受付: 11/5(木)〜12/15(火) 17:00(様式4(事業支援計画書)の発行受付締切は12/4(金)。予定は変更の場合あり)
  • もらえる額: 補助率2/3(賃金引上げ特例のうち赤字事業者は3/4)。上限50万円。インボイス特例で+50万円、賃金引上げ特例で+150万円、両方で+200万円
  • 対象になる人: 小規模事業者(商業・サービス業は常時使用する従業員5人以下、宿泊業・娯楽業と製造業その他は20人以下)。個人事業主も対象
  • 飲食店に関係する理由: 対象経費は機械装置等費・広報費・ウェブサイト関連費・展示会等出展費・旅費・新商品開発費・借料・委託・外注費。チラシやウェブサイトなど、お店の販路開拓に使える

申請の順序

  1. GビズIDプライムを取得
  2. 電子申請システムで経営計画・補助事業計画(様式2)を作る
  3. 地域の商工会議所・商工会に『事業支援計画書(様式4)』の発行を依頼(12/4締切。即日発行はできない)
  4. 電子申請で提出(11/5〜12/15 17:00)
  5. 採択(2027年3月頃予定)→ 見積書等の提出 → 交付決定の後に事業開始 → 実績報告 → 補助金の受け取り(後払い)

用意する書類(公式ページの記載より)

  • 法人: 貸借対照表と損益計算書(直近1期分)、履歴事項全部証明書または現在事項全部証明書(提出日から3か月以内)
  • 個人事業主: 直近の確定申告書(第一表・第二表と収支内訳書、または青色申告決算書)。決算を迎えていない場合は開業届と売上台帳等
  • 事業支援計画書(様式4・商工会議所/商工会が発行)
  • 特例を使う場合はその書類(公募要領の『申請に必要な書類』で確認)

よくある不備・落とし穴

  • 様式4の発行受付は12/4で締切。これを過ぎると、いかなる理由でも発行されないと公募要領に明記
  • 事業者自身が検討した計画でないと判断されると、不採択・交付決定取消。第三者の支援を受けた場合は、相手と金額の記載が必須
  • 補助金は後払い。先に自己資金で支払う必要がある
  • 通常の営業活動の経費や、単なる取替えの機械は対象外

相談先: 地域の商工会議所・商工会(様式4の発行元)。制度の問い合わせ先は各事務局サイトに掲載

どの補助金でも共通の準備

  • 国の補助金の多くは電子申請で、GビズIDプライム(無料)が必要です。取得に日数がかかることがあるので、先に申請しておくと安心です。 https://gbiz-id.go.jp/
  • 迷ったら、無料の公的窓口へ。地元の商工会議所・商工会、または各都道府県のよろず支援拠点(https://yorozu.smrj.go.jp/)。
  • 「必ず通る」「代わりに書類を作る」という有料の勧誘には注意してください。行政書士でない者が報酬を得て申請書類を作ることは、法律で禁じられています。
