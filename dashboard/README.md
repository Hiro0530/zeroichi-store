# ZEROICHI WORKS 管理画面

## 実装状況 (2026/11/21)

- GitHub Pagesへ配信する静的画面。配信成功はGitHub Actionsの実行結果で確認すること。設定ファイルをコミットしただけでは公開完了ではない。
- ブラウザのlocalStorageに案件・売上・チェック・担当・次アクションを保存する。複数端末間の自動同期は未実装。
- JSONの書出・読込は利用者が明示操作する。公開リポジトリへ案件情報を保存しない。
- 非公開リポジトリarbitrage-scoutの`zeroichi-dashboard-export.yml`が6時間ごとに非公開Actions artifactを生成する設計。実行成功は未確認。生成物はユーザーがダウンロードしてサイトに読み込む。GitHub Pagesから非公開リポジトリを直接読まない。
- 外部応募、契約、請求送信、支払いは実行しない。入力したステータスを外部サービスの実績と取り違えない。
- 公開画面に認証はない。共用端末や機密性の高い顧客情報には使用しない。業務上の秘密は非公開リポジトリに保持する。

## 本番化の未完了条件

1. GitHub Pagesのデプロイ成功とURLを実測で確認。
2. 認証・アクセス制御・監査ログを備えた非公開データ同期方式を設計・実装。
3. Actionsのスナップショット実行・テスト結果を確認。
4. 実際の応募→契約→納品→請求→入金の証拠を検証。
5. 無断支出・無断送信・個人情報公開の禁止を維持。
