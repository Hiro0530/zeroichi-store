    API の設定(はじめに1回)

    検索とAmazonの価格取得は、ご自身で無料登録した ID(Keepaは有料のAPIキー)を使って、このブラウザから直接、楽天・Keepaに問い合わせます。IDやキーはこの端末のブラウザの中だけに保存し、当方のサーバーには送りません(サーバーはありません)。

    ID・キーの取り方
    1. 楽天: Rakuten Developers に楽天会員でログインし、アプリを新規作成。「許可するWebサイト(Origin/Referer)」に https://hiro0530.github.io を入れてください(入れないと403になります)。アプリIDとアクセスキーをここに貼ります。
    2. Yahoo!: Yahoo!ショッピングのAPIはブラウザから直接使えないため、「Yahoo!ショッピング」のタブでは公式の検索ページを開きます。IDは要りません。
    3. Keepa(任意・有料): Keepa API の契約でキーが発行されます。1回の取得で1トークン(カート価格つきは3トークン)を使います。

    各サービスの利用規約に沿ってお使いください。当アプリはメルカリ・Yahoo!オークション・Amazonのページを自動で読み取る機能を持ちません。

    ウォッチ(気になる商品)

    仕入れ台帳

    5つの計算ページで共通の台帳です。CSV(Excel・Googleスプレッドシートで開けます)には古物台帳の項目(品目・特徴・相手方の氏名・住所・職業・年齢・確認の方法)も入ります。

    記帳が必要かどうか・必要な項目は、古物営業法と所轄の警察署の案内で確認してください。このツールは記録の入れ物で、法令上の判断はしません。データはこの端末のブラウザの中だけに保存され、当方には送られません。機種変更の前にCSVで書き出してください。

    使い方のコツ

    • 先に「仕入れ値の上限」を見る: 目標の利益率を決めておくと、「今の価格 ≤ 上限」かどうかだけで判断できます。
    • ポイントは別に見る: ポイントを含めない利益もいっしょに表示しています。ポイントには付与の上限や期間限定があるので、含めない利益が0円以上かも確かめてください。
    • 750円・1,000円の境目: 販売手数料は750円以下が5%、FBA配送代行手数料は1,000円以下が安い料金です。少しの値下げで手数料が変わることがあります。
    • Amazon本体が売っている商品: Keepaの結果で「Amazon本体: 在庫あり」の時は、カートを取りにくいことがあります。
    • 出品できるかを先に確認: ブランドやカテゴリーによっては出品の許可が要ります。セラーセントラルで確かめてから仕入れてください。
    手数料の改定やポイントの日程は、無料の週刊メルマガ(メール1通で登録)でお知らせします。
