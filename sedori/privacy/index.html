プライバシーポリシー(せどり 利益チェック)

制定日 2026年10月27日

ZEROICHI WORKS(以下「当方」)は、「せどり 利益チェック」(以下「本サービス」)で扱う個人情報を、次のとおり取り扱います。事業者の氏名・住所等は特定商取引法に基づく表記に載せています。

1. 扱う情報

アカウントメールアドレス。Googleでログインした場合はGoogleアカウントのメールアドレスと識別子(パスワードは当方に届きません)
台帳(スタンダード)利用者が入れた仕入れ・売却の記録。取引相手の氏名・住所・電話・メール・職業・年齢・確認の方法など、古物台帳の項目を含みます

契約PayPalのサブスクリプションID、プラン、契約の状態、無料期間の終わり・次回の請求日。カード番号・口座番号は当方に届かず、PayPalが扱います
お問い合わせメールでいただいた内容
端末の中だけの情報無料プランの台帳、入力した値、楽天・Keepaのキーは、利用者の端末のブラウザの中だけに保存し、当方には送られません

2. 利用目的

  1. ログインと、台帳・設定のクラウドへの保存・端末間の同期・書き出しのため
  2. 契約の管理(お申し込み・無料期間の終了のお知らせ・請求・一時停止・解約)のため
  3. お問い合わせへの返事、料金や規約の変更などの大切なお知らせのため
  4. 不正な利用を防ぐため

台帳の中身は、上の1のためだけに扱います。当方は台帳の中身を見たり、分析・営業・広告・AIの学習などに使ったりしません。障害の調査などで中身を見る必要が出た時は、事前に利用者の同意を得た範囲に限ります。

3. 第三者への提供の制限

  1. 当方は、法令に基づく場合などを除き、本人の同意なく個人情報を第三者に提供しません。
  2. クラウドへの保存について: 台帳と設定は、Google LLC の Firebase(Cloud Firestore)の東京リージョン(日本)に保存します。Googleは、当方との契約(データ処理の規約)に基づいてデータを保管するだけで、中身を取り扱いません。このため、個人情報保護委員会の考え方(いわゆるクラウド例外)に照らし、Googleへの「第三者提供」にはあたらないものとして扱い、当方が安全管理の責任を負います。
  3. 利用者が取引相手から得た個人情報について、当方は保管の場所を提供する立場で、その情報を取り扱いません。利用者の側でも、当方のクラウドに保存することは第三者への提供にあたらないものと考えています。
  4. 支払いはPayPal(PayPal Pte. Ltd.)、契約の状態の受け渡しは Cloudflare, Inc. の Workers、お知らせのメールの送信は Google(Gmail)を使います。これらに渡すのは、それぞれの目的に必要な情報(メールアドレス・契約の識別子など)だけで、台帳の中身は渡しません。

4. 安全管理のためにしていること

  • 通信はすべて暗号化(HTTPS)します。保存したデータもGoogleの仕組みで暗号化されます。
  • データベースの規則で、ログインした本人だけが自分の台帳を読み書きできるようにしています。ほかの利用者からは見えません。契約の状態は、当方のサーバーだけが書き換えられます。
  • 管理用のアカウントは2段階認証で守り、秘密の鍵は公開の場所に置きません。運営責任者1名だけが管理画面に入れます。
  • 外国の制度: 利用するクラウド・決済の会社は米国・シンガポール等の事業者ですが、台帳の保存場所は日本です。
  • 漏えいなどが起きた時は、法令に従って個人情報保護委員会への報告と本人への通知を行います。

5. 保存の期間

クラウドの台帳・設定契約中は保管します。解約(支払い済みの期間の終わり)から3年間保管し、その後に消します。古物台帳は最後の記入から3年間の保存が必要なため、解約後もマイページから書き出せるようにしています。利用者がマイページで消した時は、すぐ消します
アカウントアカウントを削除するまで(解約後、マイページから削除できます)
契約・請求の記録税法などの法令で決められた期間(最長7年)
お問い合わせのメール対応が終わってから1年

6. 開示・訂正・利用停止など

ご本人の情報の開示・訂正・削除・利用停止のご請求は、ログインに使うメールアドレスからzeroichi.works.jp@gmail.comへご連絡ください。ご本人であることを確かめたうえで、遅くとも2週間以内に対応します。台帳の書き出しと削除は、マイページからいつでもできます。

7. Cookie などの扱い

ログインの状態と端末の中の台帳を保つため、ブラウザの保存領域(localStorage・IndexedDB)を使います。アクセス解析と広告のための仕組みは使っていません。お申し込みの画面ではPayPalの部品を読み込み、PayPalがCookieを使うことがあります(PayPalのプライバシーステートメントに従います)。

8. このポリシーの変更

内容を変える時は、このページでお知らせします。大きく変える時は、ログインに使うメールアドレスにもお知らせします。

法律と規約の注意

古物営業法

  • 中古品を仕入れて売ることを繰り返す場合は、古物商許可が必要です(自分の不用品を売るだけなら不要)。Amazonで中古を出品する場合は、出品者情報に許可した公安委員会名と許可番号の表示も必要です。
  • 個人から1万円以上の古物を買うときは、その都度、法律で決められた方法での本人確認が必要です。ゲームソフト・CD・DVD・書籍・バイク等は金額を問わず必要です。身分証の写しを受け取るだけでは足りず、匿名配送の取引では事実上できません。1万円未満でも、18歳未満からの買い受けでないことの確認が要ります。警視庁の解説
  • 古物の取引は、年月日・品目と数量・特徴・相手方の住所氏名職業年齢・確認の方法などの記録が必要です。このアプリの台帳は記録の入れ物で、法令上の判断はしません。必要な項目は所轄の警察署で確認してください。台帳で相手確認が未入力の行には印が付きます。
  • 古物市場(業者オークション)への入会には古物商許可証が求められます。

Amazonの方針(無在庫・ドロップシッピング)

  • 記録上の販売者は自分であること、納品書・外箱・同梱物から仕入れ先の情報を除くこと、返品は自分で受けること。仕入れ先からお客様へ直接送ってもらう形はとれません。自分(または発送代行)で受け取って検品し、自分の名義で発送します。
  • 仕入れ先が売り切れたら、すぐAmazonの在庫を0にしてください。出荷前キャンセル率の目安は2.5%未満です。
  • ブランドやカテゴリーによっては出品の許可が要ります。セラーセントラルで確かめてから仕入れてください。

写真と説明文

  • 仕入れ先(ヤフオク・メルカリ等の出品者)の写真や文章を、自分の出品にそのまま使わないでください。著作権の問題になります。自分で撮った写真を使い、Amazonでは既存の商品ページに相乗りしてコンディションを文字で説明します。

自動アクセス

  • このアプリはメルカリ・Yahoo!オークション・業者オークション・Amazonのページを自動で読み取りません。検索は各サイトの検索ページを新しいタブで開くだけです。楽天とKeepaは、ご自身のIDとキーで公式APIを使います。
