# 帳簿: 取り込みと書き出しの形式(確認日 2026-10-27)

帳簿(/sedori/books/)が読む形式と、会計ソフト向けに書き出す形式のメモ。計算は `assets/books-core.js`、検算は `test/books-core.test.js`(`node --test sedori/books/test/*.test.js`)。

## 読む形式

### Amazon ペイメントレポート(日付範囲レポート・トランザクション)
- 見出しの行は先頭20行から探す(日本語版は説明の行が前に数行ある)。日本語・英語の見出しの両方に対応。UTF-8 / Shift_JIS を自動で判別。
- 列(日本語): 日付/時間, 決済番号, トランザクションの種類, 注文番号, SKU, 説明, 数量, Amazon 出品サービス, フルフィルメント, 市町村, 都道府県, 郵便番号, 税金徴収型, 商品売上, 商品の売上税, 配送料, 配送料の税金, ギフト包装手数料, ギフト包装クレジットの税金, Amazonポイントの費用, プロモーション割引額, プロモーション割引の税金, 源泉徴収税を伴うマーケットプレイス, 手数料, FBA 手数料, トランザクションに関するその他の手数料, その他, 合計
- 種類: 注文 / 返金 / 調整 / 振込み / FBA在庫関連の手数料・サービス料金・注文外料金・数量限定タイムセール手数料(手数料として扱う)
- 内訳(売上+値引き+源泉−手数料+その他)と「合計」が1円より大きくずれた行は警告し、差を調整に入れる。
- 重複の判定キー: 決済番号・日付・種類・注文番号・SKU・合計・売上・手数料。同じ期間を2回入れても二重にならない。
- 出典: 列名と種類の一覧 https://www.tool4seller.com/jp/blog/transaction-report-glossary.html (確認 2026-10-27)。実物の列名と合わない場合は `AMZ_COLS` に別名を足す。

### メルカリ(個人)
- 個人の売上は公式のCSVが無い(メルカリShopsのみ)。取引画面・売上履歴の文字を貼り付けて読む(自動アクセスはしない)。
- 読む項目: 商品代金 / 販売手数料 / 配送料 / 販売利益 / 購入日時 / 商品ID。手数料が無ければ10%で計算し「推定あり」の印。売上履歴(利益だけ)は利益を売上として入れ、取引画面を貼ると内訳に分かれる。

### 汎用CSV(カード明細・ほかの売上表)
- 見出しの名前と中身(日付らしい列・金額らしい列・文字の長い列)から列を推測し、画面で直せる。取り込む先は「売上」か「経費」。
- 経費は支払先の文字から科目を推測(ヤマト→荷造運賃、ダイソー→消耗品費、ドコモ→通信費 等)。画面で直した科目は支払先ごとに覚える。

## 書き出す形式(仕訳帳)

| ソフト | 形 | 文字コード(既定) | 出典・確認日 |
|---|---|---|---|
| freee会計 | 伝票番号, 発生日, 借方勘定科目, 借方税区分, 借方金額, 借方税額, 貸方勘定科目, 貸方税区分, 貸方金額, 貸方税額, 摘要(エクセルインポートの振替伝票。列はfreee側で当てはめる) | UTF-8(BOM付き) | https://support.freee.co.jp/hc/ja/articles/216527163 ・取引の項目 https://support.freee.co.jp/hc/ja/articles/202847320 (2026-10-27) |
| マネーフォワード クラウド確定申告 | 取引No, 取引日, 借方勘定科目, 借方補助科目, 借方部門, 借方取引先, 借方税区分, 借方インボイス, 借方金額(円), 借方税額, 貸方勘定科目, 貸方補助科目, 貸方部門, 貸方取引先, 貸方税区分, 貸方インボイス, 貸方金額(円), 貸方税額, 摘要, 仕訳メモ, タグ, MF仕訳タイプ, 決算整理仕訳(日付は yyyy/MM/dd) | Shift_JIS | https://biz.moneyforward.com/support/tax-return/guide/import-books/ib01.html (ページの更新日 2026-07-09、確認 2026-10-27) |
| やよいの青色申告 | 弥生インポート形式25項目・見出しなし。識別フラグ2000(1行の仕訳)、取引日付 yyyy/mm/dd、金額は税込の整数、タイプ0、調整 no | Shift_JIS | https://support.yayoi-kk.co.jp/subcontents.html?page_id=18545 (2026-10-27) |
| 汎用 | 番号, 日付, 借方, 借方金額, 貸方, 貸方金額, 摘要 | UTF-8 | — |

- 税区分: 免税事業者はすべて「対象外」。課税事業者は 売上=課税売上10% / 仕入・経費=課対仕入10%(弥生は「課税売上込10%」「課対仕入込10%」、MFは「課税売上 10%」「課税仕入 10%」)。経過措置(80%・70%等)の区分やインボイス欄は入れていないので、取り込み後にソフト側で確認する。
- 科目名の差: freee は「期首商品棚卸」「期末商品棚卸」。ほかは「期首商品棚卸高」「期末商品棚卸高」「商品」。支払いの科目の既定は「事業主借」、売上は「売掛金」→Amazonの振込みで「普通預金」。

## 申告用の数字
- 売上原価 = 期首商品棚卸高 + 仕入金額 − 期末商品棚卸高。期首は前の年の12月31日時点の台帳の在庫(手で上書き可)、期末は棚卸の画面の金額(実地の数を反映)。
- 評価: 最終仕入原価法(届出をしていない場合の方法。同じJAN・ASIN・品名は最後の仕入れ値で評価)/ 個別法。
- 欄の番号: 青色申告決算書(一般用)①〜⑦・⑧〜㉝、収支内訳書(一般用)①〜⑩・⑪〜⑲。収支内訳書の番号は https://www.freee.co.jp/kb/kb-shiroiroshinkoku/balance (2026-10-27)で確認。様式は年によって変わるので画面に注意書きを出す。
- 表示はすべて参考の値。個別の税務の判断はしない(税理士法)。「税理士いらず」等の表現は使わない。

## 古物商特例(課税事業者のみ)
- 対象: 古物商が適格請求書発行事業者でない者から買い受けた古物(棚卸資産)。帳簿に、売り手の氏名・住所(古物営業法で確認が要る取引のみ)、年月日、品名、数量、対価、特例の対象である旨を記載。1万円未満で確認の要らない品は氏名・住所なしでよい(ゲーム・CD・DVD・書籍・バイク・エアコン室外機等は金額を問わず要る)。
- 事業者(店舗・ショップ)からの仕入れは適格請求書の保存が必要なので「事業者」に分ける。書き出す仕訳の摘要に「古物商特例」と入れる。
- 出典: 国税庁 インボイス制度Q&A https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/01-13.pdf ・問106 https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/106.pdf (問106 令和8年5月改訂、確認 2026-10-27)。記載事項の詳細は同Q&Aの問110。
