# ほかのAI予想アカウントとの比べ方(公平な答え合わせ)

目的: 「どちらがよく当たるか・どちらが損が小さいか」を、同じ条件・同じ物差しで、数字の幅(95%区間)と件数つきで出す。勝っていない期間・券種もそのまま出す。

## 1. 公平にするための決まり

| 決まり | 理由 |
|---|---|
| 同じレース・同じ券種だけを比べる(相手が予想したレースで、私たちも同じ日の朝に公開した予想があるものだけ) | 相手は自信のあるレースだけ出すことが多い。全レースの私たちと比べると相手に有利になる |
| 点数をそろえる(上位k点、k=相手の点数と私たちの点数の少ない方、最大3点) | 点数が多いほど当たるのは当然なので |
| 締切より前に出ていた予想だけ(相手は投稿時刻、私たちは公開時刻 `published_at`) | 後出しを数えない。相手の投稿時刻が分からないものは「時刻不明」として件数を別に書く |
| 答え合わせは公式の競走成績(着順・確定払戻) | どちらの自己申告も使わない |
| 回収率は毎回100円/点で機械的に | 相手の「推し金額」や表示上の回収率は使わない |
| 件数と95%区間を必ず出す(的中率はウィルソン、差と回収率はレース単位のブートストラップ) | 数十レースでは差があるとは言えないことが多い。100レース未満は「参考」 |
| 集めるのは公開の投稿を手で(Muse が記録)。X を自動で読みに行かない | 利用規約と相手への配慮 |
| 相手の名前は社内の記録だけ。公開する比較では、相手の了承が無ければ名前を出さない(「A社」「B」など) | 相手を貶める見せ方をしない。数字の出し方を公開して、誰でも確かめられるようにする |

## 2. 入力の形(CSV、UTF-8、1行=1点)

```
date,venue,race,source,bet_type,combo,rank,posted_at
2026-10-28,大村,5,アカウントA,3連単,1-2-3,1,2026-10-28T14:52:00+09:00
2026-10-28,大村,5,アカウントA,3連単,1-3-2,2,2026-10-28T14:52:00+09:00
2026-10-28,24,6,アカウントA,単勝,1,1,
```

- `venue`: 場の名前(大村)か2桁のコード(24)。`race`: レース番号
- `source`: 予想元の名前(私たちの分は自動で足すので書かない。`ZEROICHI` は使えない)
- `bet_type`: 単勝 / 複勝 / 2連単 / 2連複 / 拡連複 / 3連単 / 3連複。`combo`: `1-2-3`(連複は順不同でよい)
- `rank`: 相手が付けた順番(1が本命)。順番が書かれていなければ投稿に並んでいる順
- `posted_at`(任意): 投稿の時刻。締切より後なら数えない。空欄なら時刻不明として数える(表の下に件数)
- 置き場所: 非公開リポジトリ(arbitrage-scout)の `kyotei_rivals/rivals_YYYYMM.csv` を推奨(相手の名前を公開リポジトリに置かないため)

## 3. 実行

```
python kyotei/rival_grade.py rivals.csv            # 表を出す
python kyotei/rival_grade.py rivals.csv --json out.json --k 3
```

出力(予想元×券種ごと): レース数、1点目の的中率 [95%]、上位k点の的中率 [95%]、1点目・上位k点の回収率 [95%](払戻が分かったレース数 n)、差(私たち − 相手)の的中率のポイント差 [95%]。数えなかったもの(結果が無い・締切後の投稿・私たちがその券種を公開していない)の件数も出す。

払戻: 単勝・3連単・2連単(2026-10-28の予想から)は `results/` から分かる。複勝・2連複・拡連複・3連複は、非公開の履歴(`hist/`、Actions の中)があるときだけ分かる。分からないレースは回収率から外し、n に表れる。的中率はどの券種でも出せる。

## 4. 私たちの側の買い目(公開時に決めたものだけ)

| 券種 | 私たちの買い目 |
|---|---|
| 単勝 | 1着の確率の高い順 |
| 複勝 | 2着以内の確率が最も高い艇(1点) |
| 2連単 | 確率の上位3点(2026-10-28 の予想から公開) |
| 3連単 | 確率の上位3点 |
| 3連複 | 確率の上位3点(2026-10-27 から) |
| 2連複・拡連複 | 公開していないので比べない |

## 5. 読み方の注意

- 1日1〜2レースしか出さない相手と比べるときは、数か月分たまるまで結論を出さない(3連単3点の的中率の95%区間は、100レースで ±8〜9ポイントほど)。
- 的中率が高くても回収率が高いとは限らない(1号艇の本命は当たりやすいが払戻が低い)。両方を並べる。
- 回収率が100%を超えたように見えても、区間の下端が100%を超えていなければ「偶然と区別できない」と書く。
- 比べた結果は `experiments/` には置かない(相手の名前が入るため)。公開するときは名前を伏せ、件数・区間・比べ方(このファイル)へのリンクを必ず付ける。
