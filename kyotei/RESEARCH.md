# kyotei: 次に試す実験(研究用のメモ)

前提(変えない): 予想に使うのはレースの朝までに分かる数字だけ。公式ページの直前情報・オッズは取得しない。検証は `exp_v3.py` と同じウォークフォワード(選ぶ期間と確かめる期間を分ける)、残す基準は対数損失の差の95%区間の上端が0未満。結果は `experiments/` に集計だけを残す。

## 高い自信度の帯(S)を広げる・当てる
1. 自信度を「本命の確率」だけでなく、本命と2番手の確率の差・モデル間(アンサンブル要素)のばらつきでも分ける。しきい値は選ぶ期間で決め、確かめる期間で評価。
2. 1号艇の本命だけでなく、2〜6号艇が本命のレースの的中率を別に見る(1号艇以外の本命は外れやすい。帯を分けると S の的中率が上がる可能性)。
3. 自信度ごとの確率の当たり具合(較正)を場ごとに見て、ずれていれば場ごとの温度(確率の鋭さ)を学習外で合わせる。

## 特徴量
4. 選手×コース(実際の進入)の最近90日、前付けする選手が同じレースにいるときの1号艇の不利(レース内の相互作用)。
5. 展示タイムの代わり: レースタイム(`rt`、v3から記録)を場・距離・気象で補正した「足の速さ」。履歴がたまってから(半年後)。
6. モーター: 入れ替え直後の期間は B ファイルの2連率を弱め、モーター番号の最近の成績を強める(期間で効き方を変える交互作用)。
7. 選手の「整備・調整の力」: 同じ選手が乗ったモーターの平均と比べた成績を、長い期間(1年)で。
8. 今節の流れ: 今節の初日・最終日・優勝戦、選手の今節の着順の傾き(番組表の今節成績から)。
9. 気象: アメダスの朝の観測(`hist/jma/amedas/`、2026-10-25から毎朝保存)が90日たまったら、前日の風と入れ替えて検証。気象庁の「過去の気象データ・ダウンロード」で過去の毎時の風を少ない回数で取れるかも調べる(取得回数と利用条件を先に確認)。
10. 潮位: 満潮・干潮からの時間(潮止まり付近か)、潮位の日変化の大きさ(大潮・小潮)。

## モデル
11. 2着・3着の別モデル(今は Harville + 補正)。3連単の的中率に効く。
12. 選手の強さをレースごとに推定する順位モデル(Plackett-Luce)で、1着だけでなく着順全体から学習。
13. 勾配ブースティングは v2 で不採用。特徴量が増えたので、条件付きロジットとの平均(アンサンブル)だけもう一度試す。

## 評価
14. 確かめる期間を増やす(履歴が3年分そろったので、12週×2)。
15. 公開後の実績(`summary.json` の `tiers`)と学習外の検証の差を毎月見る(ずれが大きければ、検証のどこかで未来の情報が混ざっている疑い)。

## 結果: 舟券の種類・自信度・場ごとの仮の回収率(2026-10-26、`exp_roi.py` → `experiments/roi_v3.json`)

v3 の構成で直近16週を1週ずつウォークフォワード。前半8週(見つける期間 2026-07-06〜08-30、8,860レース)で区分を探し、後半8週(確かめる期間 2026-08-31〜10-25、8,612レース)だけで評価。毎回100円(3連単は1点100円、上位k点)、確定払戻金で計算。[ ]はレース単位のブートストラップ95%区間。

確かめる期間の回収率(的中率):

| 舟券 | 全体 | S | A | B | C |
|---|---|---|---|---|---|
| 単勝◎ | 90.9% [88.7, 92.9](57.1%) | 93.9% [91.6, 96.4](76.0%) | 88.6% [85.5, 91.5] | 91.4% [85.1, 98.4] | 90.2% [82.4, 98.3] |
| 3連単 上位3点 | 76.3% [72.7, 80.1](23.0%) | 79.5% [74.2, 85.0](29.9%) | 74.3% [69.3, 79.6] | 80.6% [69.7, 91.7] | 71.9% [61.6, 83.5] |
| 3連単 上位5点 | 77.4% [74.6, 80.4](33.3%) | 81.6% [77.4, 86.3](43.2%) | 75.4% [71.2, 79.7] | 79.4% [70.9, 88.1] | 73.2% [64.7, 82.4] |
| 3連単 上位10点 | 78.5% [76.1, 80.9](51.0%) | 81.7% [78.1, 85.6](63.3%) | 79.4% [75.6, 83.2] | 76.6% [69.7, 83.6] | 72.5% [66.4, 78.6] |

レース数: S 2,669 / A 3,258 / B 1,133 / C 1,552。

- 見つける期間で回収率100%以上(100レース以上)だったのは、調べた316区分(舟券4種 × 全体・自信度・場・自信度×場など)のうち15区分。確かめる期間で区間の下端が100%を超えたものは **0**。15区分の多くは確かめる期間で62〜94%に下がった(例: 江戸川のA×3連単3点 114% → 62%、平和島×3連単3点 102% → 69%)。316区分も調べれば偶然100%を超えるものが出るのは当然で、それと区別できない。
- 確かめる期間でいちばん高かったのは 下関×単勝◎ 102.9% [91.7, 115.2](360レース)で、100%を超えているとは言えない。
- 3連単の払戻は高いが当たりにくく、上位3〜10点はどの自信度でも72〜82%。単勝◎(89〜94%)より低い。払戻率75%(控除25%)を考えると、単勝◎の 91〜94% は「市場の平均よりはだいぶ良い」が、100%には届かない。
- 公開後の実績(10/23〜10/25、503レース。自信度は当時の確率に今のしきい値を当てはめて計算): 単勝◎ 89.5% [81.6, 97.9]、3連単3点 76.6% [61.4, 90.4]。そのうちS(162レース)は単勝 95.9% [86.9, 105.6]、3連単3点 81.4% [61.9, 103.3]。ページの「今日の自信あり」5レース×3日(15レース)は3連単3点 139.6% [84.4, 206.0] だが、15レースでは何も言えない(1日1本の 400〜1,180円の的中で大きく動く)。
- 結論: いまのモデルで、回収率100%以上が続く舟券の種類・自信度・場は見つかっていない。オッズを使わない限り、期待値で勝つ買い方を示すことはできない(README「オッズについて」)。

次に試すなら: 3連単の2・3着の精度を上げる(上の11・12)、本命以外の「穴」の確率の当たり具合を確かめる。区分を探すときは今回と同じく、見つける期間と確かめる期間を分けること。

## 結果: 全券種 × 自信度 × 選び方(2026-10-26、`exp_bets.py` → `experiments/bets_v3.json`)

全券種の払戻を履歴に足した(直近182日、K ファイルを1ファイル3秒で取り直し。払戻がそろったレース 99.9%)。見つける期間 2026-07-06〜08-30、確かめる期間 2026-08-31〜10-25(8,604レース)。確率は1着の確率 → 3連単の確率(Harville+補正)から各券種へ足し合わせ。毎回100円/点。

確かめる期間の回収率 [95%区間](的中率):

| 券種・点数 | 全体 | S(2,666レース) |
|---|---|---|
| 単勝◎ 1点 | 90.9% [88.8, 93.2](57%) | 94.0% [91.6, 96.3](76%) |
| 複勝◎ 1点 | 94.4% [92.9, 96.1](75%) | 95.9% [94.3, 97.6](89%) |
| 2連単 1点 / 3点 | 82.2% / 81.4% | 84.1% / 84.9%(31% / 65%) |
| 2連複 1点 / 3点 | 85.4% / 83.2% | 84.9% / 85.7%(37% / 76%) |
| 拡連複 1点 / 3点 | 86.1% / 83.3% | 85.5% / 83.9%(61% / 91%) |
| 3連単 1点 / 3点 / 5点 / 10点 | 73.9% / 76.4% / 77.5% / 78.6% | 73.6% / 79.6% / 81.7% / 81.8%(11% / 30% / 43% / 63%) |
| 3連複 1点 / 3点 / 5点 | 75.9% / 80.1% / 79.4% | 77.2% / 82.4% / 82.5%(25% / 57% / 75%) |

- 3連複は3連単より当たりやすい(Sで1点 25% 対 11%、3点 57% 対 30%)が、払戻が低いぶん回収率は同じくらい(77〜83%)。「当たる回数」と「収支」は別。
- いちばん回収率が高いのは 複勝◎(S 95.9%)と 単勝◎(S 94.0%)。どれも100%未満。券種の控除率は同じ25%だが、本命側の券種ほど損が小さい(本命・大穴の偏り: 大穴ほど実際より高い確率で買われ、払戻が割に合わない)。
- (2) ◎の確率 X 以上 かつ ◎が1着のときの2着の散らばり(エントロピー)が小さいレースだけ: 15券種×28条件=420通りから、見つける期間でいちばん良い条件を券種ごとに選び、確かめる期間で評価。いちばん良いのは 複勝(X≥0.80、散らばり下位50%、344レース)96.1% [92.1, 100.8]、単勝(X≥0.75)94.2% [88.3, 100.3]。100%を超えたと言えるものは無し。
- (3) オッズの代わりに「組番ごとの過去の平均払戻」×確率 ≥ t の組番だけ: 7券種×8条件=56通り。確かめる期間は 単勝 92.6% [82.8, 104.0]、複勝 89.7%、拡連複 84.5%、3連単 74.2%。平均払戻は「その組番が当たったときの平均」で、レースごとの人気を反映しないので、オッズの代わりにはならない。
- 確かめる期間で区間の下端が100%を超えたものは **0**(476通り)。

## 結果: 今日の穴(万舟ねらい)(2026-10-26、`exp_ana.py` → `experiments/ana_v3.json`)

1日の中で「万舟らしさ」(過去の平均払戻が1万円以上の組番の確率の合計)が高いレースを選び、◎が1着の組番を除いて平均払戻が高い組番を確率順に。18通り(1日2〜3レース × 3/5/10点 × 平均払戻3,000/5,000/10,000円以上)から見つける期間で選び(2レース・3点・1万円以上)、確かめる期間で評価:

- 112レース、的中10本(8.9%)、当たったときの平均払戻 2,210円、**万舟の的中 0本**、回収率 65.8% [25.9, 112.8]。
- 選んだレースが実際に万舟になった割合は 14.9%で、全レースの 16.0% と変わらない。モデルが見積もった万舟の確率(平均64%)は大きくずれている。つまり今の作り方では「万舟になりやすいレース」を見分けられていない。
- 本命・大穴の偏り(大穴は買われすぎて払戻が割に合わない)があるので、穴の組番は回収率がさらに下がりやすい。
- 結論: 万舟ねらいとしては働いていない。毎日の予想ファイルに記録として作り(`ana`)、翌朝答え合わせして `summary.json` の `total.ana` に積み上げるが、ページとXでは出していない(本部の判断待ち)。有料の目玉にするのは勧めない。

## 当日の気象と、昼の予想のやり直しについて

- 今のモデルは当日の気象を使っていない。使っているのは、前日の同じ場の風速・波高と、前のレースまでの展示タイム(選手ごと・モーター番号ごと)。
- 当日のレース時の実際の風(向きつき・場ごとの係数)を足しても、対数損失の改善は 0.0008(区間は0をまたぐ)で、1着的中率は変わらなかった。前もって分かる風(アメダスの昼の観測)ではこれより小さい。
- v2 の参考検証で「当日の風・波・展示タイム」を全部入れると 1.198 → 1.185 だったが、ほとんどは当日の展示タイム(直前情報のページにしか無く、取得しない)の分。
- 昼にアメダスで予想をやり直す価値は低い(改善の上限が小さいうえ、公開時刻の証明が2回になって分かりにくくなる)。アメダスの朝の観測は毎朝貯めているので、90日たまったら同じ方法で検証する。

## 結果: 券種ごとの組番の確率の当たり具合(2026-10-26、`exp_calib.py` → `experiments/calib_v3.json`)

確かめる期間 2026-08-31〜10-25(8,604レース)。予想確率の区分ごとの実際の的中率。
- 全体ではよく合っている(例: 3連単 2-5% → 実際 3.0%、5-10%(平均6.6%)→ 7.5%、単勝 40%以上(平均62.5%)→ 62.0%)。
- ずれが大きいのは自信度Sの小さい確率: 「◎1着+人気薄(1着の確率4位以下)が2・3着」の3連単で、予想1.24% → 実際0.63%(14,374点、約2倍の見積もりすぎ)。2連複 S 5-10%(平均7.6%)→ 4.7%、3連複 S 2-5%(平均3.5%)→ 2.4%。S のレースで◎以外の組み合わせを高く見すぎている。
- 区分の組番を全部100円ずつ買うと(点数が分かるので計算できる)、どの券種・区分も回収率 41〜94%(件数の少ない区分を除く)。
- 当たった組番のうち「確率×確定オッズ≥1.2」だった割合: 単勝 12.4% → 較正後 11.3%、2連単 11.0% → 9.1%、2連複 11.0% → 9.2%、3連複 10.5% → 8.6%、3連単 12.4% → 10.4%(較正=前半8週の単調回帰を後半に適用)。較正で「期待値が高く見える当たり」は1〜2割減る。
- 分からないこと: 外れた組番のオッズは確定払戻に無いので、「確率×オッズ≥1.2 の組番だけ買った」回収率は履歴からは計算できない。紙の上だけの検証(締切前のオッズの記録)でしか測れない。
