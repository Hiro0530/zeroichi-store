# kyotei: 次に試す実験(研究用のメモ)

前提: 公開する朝の予想に使うのはレースの朝までに分かる数字だけ。直前情報・オッズは、2026-10-26 のオーナー判断以降、非公開の紙の上の検証(odds_paper、1日200回まで)でだけ読む。検証は `exp_v3.py` と同じウォークフォワード(選ぶ期間と確かめる期間を分ける)、残す基準は対数損失の差の95%区間の上端が0未満。結果は `experiments/` に集計だけを残す。

## 高い自信度の帯(S)を広げる・当てる
1. 自信度を「本命の確率」だけでなく、本命と2番手の確率の差・モデル間(アンサンブル要素)のばらつきでも分ける。しきい値は選ぶ期間で決め、確かめる期間で評価。
2. 1号艇の本命だけでなく、2〜6号艇が本命のレースの的中率を別に見る(1号艇以外の本命は外れやすい。帯を分けると S の的中率が上がる可能性)。
3. 自信度ごとの確率の当たり具合(較正)を場ごとに見て、ずれていれば場ごとの温度(確率の鋭さ)を学習外で合わせる。

## 特徴量
4. 選手×コース(実際の進入)の最近90日、前付けする選手が同じレースにいるときの1号艇の不利(レース内の相互作用)。
5. 展示タイムの代わり: レースタイム(`rt`、v3から記録)を場・距離・気象で補正した「足の速さ」。履歴がたまってから(半年後)。
6. モーター: 入れ替え直後の期間は B ファイルの2連率を弱め、モーター番号の最近の成績を強める(期間で効き方を変える交互作用)。
7. 選手の「整備・調整の力」: 同じ選手が乗ったモーターの平均と比べた成績を、長い期間(1年)で。
8. 今節の流れ: 今節の初日・最終日・優勝戦、選手の今節の着順の傾き(番組表の今節成績から)。
9. 気象: アメダスの朝の観測(`hist/jma/amedas/`、2026-10-25から毎朝保存)が90日たまったら、前日の風と入れ替えて検証。気象庁の「過去の気象データ・ダウンロード」で過去の毎時の風を少ない回数で取れるかも調べる(取得回数と利用条件を先に確認)。
10. 潮位: 満潮・干潮からの時間(潮止まり付近か)、潮位の日変化の大きさ(大潮・小潮)。

## モデル
11. 2着・3着の別モデル(今は Harville + 補正)。3連単の的中率に効く。
12. 選手の強さをレースごとに推定する順位モデル(Plackett-Luce)で、1着だけでなく着順全体から学習。
13. 勾配ブースティングは v2 で不採用。特徴量が増えたので、条件付きロジットとの平均(アンサンブル)だけもう一度試す。

## 評価
14. 確かめる期間を増やす(履歴が3年分そろったので、12週×2)。
15. 公開後の実績(`summary.json` の `tiers`)と学習外の検証の差を毎月見る(ずれが大きければ、検証のどこかで未来の情報が混ざっている疑い)。

## 結果: 今日の穴(万舟ねらい)(2026-10-26、`exp_ana.py` → `experiments/ana_v3.json`)

1日の中で「万舟らしさ」(過去の平均払戻が1万円以上の組番の確率の合計)が高いレースを選び、◎が1着の組番を除いて平均払戻が高い組番を確率順に。18通り(1日2〜3レース × 3/5/10点 × 平均払戻3,000/5,000/10,000円以上)から見つける期間で選び(2レース・3点・1万円以上)、確かめる期間で評価:

- 112レース、的中10本(8.9%)、当たったときの平均払戻 2,210円、**万舟の的中 0本**、回収率 65.8% [25.9, 112.8]。
- 選んだレースが実際に万舟になった割合は 14.9%で、全レースの 16.0% と変わらない。モデルが見積もった万舟の確率(平均64%)は大きくずれている。つまり今の作り方では「万舟になりやすいレース」を見分けられていない。
- 本命・大穴の偏り(大穴は買われすぎて払戻が割に合わない)があるので、穴の組番は回収率がさらに下がりやすい。
- 結論: 万舟ねらいとしては働いていない。毎日の予想ファイルに記録として作り(`ana`)、翌朝答え合わせして `summary.json` の `total.ana` に積み上げるが、ページとXでは出していない(本部の判断待ち)。有料の目玉にするのは勧めない。

## 結果: 券種ごとの組番の確率の当たり具合(2026-10-26、`exp_calib.py` → `experiments/calib_v3.json`)

確かめる期間 2026-08-31〜10-25(8,604レース)。予想確率の区分ごとの実際の的中率。
- 全体ではよく合っている(例: 3連単 2-5% → 実際 3.0%、5-10%(平均6.6%)→ 7.5%、単勝 40%以上(平均62.5%)→ 62.0%)。
- ずれが大きいのは自信度Sの小さい確率: 「◎1着+人気薄(1着の確率4位以下)が2・3着」の3連単で、予想1.24% → 実際0.63%(14,374点、約2倍の見積もりすぎ)。2連複 S 5-10%(平均7.6%)→ 4.7%、3連複 S 2-5%(平均3.5%)→ 2.4%。S のレースで◎以外の組み合わせを高く見すぎている。
- 区分の組番を全部100円ずつ買うと(点数が分かるので計算できる)、どの券種・区分も回収率 41〜94%(件数の少ない区分を除く)。
- 当たった組番のうち「確率×確定オッズ≥1.2」だった割合: 単勝 12.4% → 較正後 11.3%、2連単 11.0% → 9.1%、2連複 11.0% → 9.2%、3連複 10.5% → 8.6%、3連単 12.4% → 10.4%(較正=前半8週の単調回帰を後半に適用)。較正で「期待値が高く見える当たり」は1〜2割減る。
- 分からないこと: 外れた組番のオッズは確定払戻に無いので、「確率×オッズ≥1.2 の組番だけ買った」回収率は履歴からは計算できない。紙の上だけの検証(締切前のオッズの記録)でしか測れない。

## 結果: 2着・3着の条件付きモデル(2026-10-26、`exp_cond.py` → `experiments/cond_v3.json`)

2着 P(j|1着i)・3着 P(k|i,j) を条件付きロジットで直接学習(直近365日、1週ずつ)。後半8週(8,612レース)で、いまの方法(Harville+補正)と比較:
- 対数損失: 2着 1.387 → 1.358、3着 1.287 → 1.252、3連単 3.851 → 3.787(差 −0.064 [−0.073, −0.056]、はっきり改善)。
- 3連単の確率の当たり具合も改善(いまの方法は 1〜3% を高く、6〜20% を低く見ていた。条件付きは各区分でほぼ一致)。
- 的中率: 3連単1点 8.9% → 9.8%、3点 23.0% → 23.9%、3連複3点 53.1% → 53.8%。自信度S: 3連単1点 11.3% → 13.1%、3点 29.9% → 31.0%、3連複3点 57.2% → 57.3%。
- 3連複・3連単の区分探し(条件付きの確率で、上位k点を全部買う。自信度×2着の散らばり×前日の風×水面 で 486通り): 確かめる期間で100%を超えたと言えるものは 0。いちばん高いのは 3連単5点 S×散らばり下位25%×淡水 101.0% [83.8, 118.4](199レース)、3連複1点 S×前日の風4m以上×海水・汽水 99.5% [79.4, 121.2](189レース)。全体は 76〜79%。


## 結果: v4 — 1年分の学習外での診断・新しい候補・直前情報・確定オッズとの比較(2026-10-28、`exp_v4.py` → `experiments/v4.json`)

直近52週(2025-10-29〜2026-10-27、55,476レース)を1週ずつウォークフォワード(その週より前の365日で学習。2着・3着は4週ごとに学習し直し)。前半26週(〜2026-04-28、27,107レース)= 選ぶ期間、後半26週(2026-04-29〜、28,369レース)= 確かめる期間。残す基準は今までと同じ(対数損失の差の95%区間の上端が0未満)。

### 1) いまのモデルの実力(52週・学習外)

| 指標 | いまのモデル | 比較 |
|---|---|---|
| ◎の1着率 | 57.2% | 1号艇を毎回 55.0%(差 +2.2pt [+1.9, +2.4]) |
| 1着の対数損失 / Brier | 1.1825 / 0.580 | 確率の当たり具合のずれ(ECE)0.003 |
| 2連単 上位1 / 3 / 5点の的中 | 23.6% / 51.2% / 65.6% | |
| 3連単 上位1 / 3 / 5 / 10点の的中 | 10.0% / 24.4% / 34.8% / 51.7% | |
| 単勝◎ / 2連単1点 / 3連単3点 の回収率 | 91.4% / 80.5% / 78.5% | 1号艇の単勝 90.3% |

- 1着の確率の当たり具合はほぼ正確(例: 予想55% → 実際55.0%、65% → 66.1%)。80%以上の本命だけ少し高く見すぎ(84% → 82.0%、92% → 88.4%)。3連単の組番も各区分でほぼ一致。
- 自信度: S(16,615レース)◎75.9% / 同じレースの1号艇 75.7%、A 57.8% / 55.6%、B 44.3% / 39.8%、C 35.1% / 31.5%。
- 当たりにくい条件: 風7m以上(◎49.7%)、波6cm以上(50.0%)、前付けなど進入が枠と変わったレース(10,546レース、◎50.8%、対数損失 1.31)。場では江戸川・戸田・平和島が低い(47〜49%)。1号艇との差が大きいのは戸田・平和島・桐生・鳴門(+4〜5pt)。

**なぜ確率がこうなるか**: 1号艇の1着が55%と構造的に強く、◎の85%は1号艇になる。モデルの仕事の大半は「1号艇がどれくらい逃げるか」(S〜C の振り分け)で、ここは当たり具合も良い。一方、1号艇が負けたレースで勝つ艇(2〜6号艇)を当てる力は弱い(2号艇が勝ったレースでその艇を◎にしていたのは20%)。2〜6号艇の勝ちは「その日の足・スタート・展開」で決まる部分が大きく、朝の数字だけでは見えないから。

### 2) 市場(確定オッズ)と比べると

当たった組番の市場の確率 = 0.75 ÷ オッズ(払戻率75%)。確かめる期間、当たった組番だけの対数損失(小さいほど良い):

| 券種 | モデル | 確定オッズ | モデル − 市場 [95%] | 線形に混ぜた最適なモデルの重み |
|---|---|---|---|---|
| 2連単 | 2.534 | 2.477 | +0.057 [+0.052, +0.062](市場が良い) | 0.15(混ぜると −0.003) |
| 3連単 | 3.779 | 3.667 | +0.112 [+0.106, +0.118](市場が良い) | 0.0(混ぜても良くならない) |
| 単勝 | 1.179 | 1.213 | −0.034(参考) | 0.65 |

- 2連単・3連単は確定オッズの方がはっきり良い。確定オッズには展示タイム・直前の気象・進入の情報も入っている。モデルの朝の情報はほとんど市場に織り込まれている。
- 単勝は「0.75÷オッズ」が本命・大穴の偏り(本命が割安、大穴が割高)をそのまま含み、正しい市場の確率にならないので、この比較では決められない(本命の単勝の回収率が90%を超えるのも同じ偏り)。
- 結論: オッズと比べて「割安」を探すとき、モデルの重みは2連単・3連単では小さくする(`odds_paper.W_BY_BET`)。

### 3) 朝に分かる新しい候補

### 今までの穴(exp_ana)が働かなかった理由
1. レースの選び方が「万舟」ではなく「1号艇の弱さ」を拾っていた(1号艇の負けのAUC 0.71、万舟のAUC 0.56)。1号艇が弱いレースは別の本命が勝つことが多く、払戻は1万円に届かない。
2. 「組番ごとの過去の平均払戻」はそのレースのオッズではない。人気の偏りが分からず、1万円以上の組番を当てても配当が低いことが多い。
3. 自信度Sのレースで◎以外の小さな確率を約2倍高く見ていた(calib_v3)。
4. 3点では万舟(約6〜16分の1の事象の中の、さらに1点)にほとんど届かず、112レースでは結果が偶然と区別できない。

### 結論
- **見分けること自体はできる**: 混戦度の上位3レース/日は、万舟率が 16% → 26%、1号艇の1着が 55% → 30%。直前の強い風・波・展示の遅さ・進入の乱れは朝のモデルが見落としている(直前版で補える)。
- **当てに行って儲かる買い方は見つからなかった**: 392通りで、確かめる期間に回収率100%を超えると言えるものは無し。「万舟は簡単」とは言えない(荒れやすいレースでも4分の3は万舟にならず、なっても払戻の高い組番は買われすぎている)。
- 毎朝の予想ファイルに「荒れ注意」(混戦度の上位3レース)と、2026-10-29 に決めた3つの買い目案(単勝 3・4号艇の上位1点、3連単 3・4号艇頭6点、3連単 1号艇以外が頭10点)を**記録だけ**する(`are.py`、`are_config.json` の `show: false`)。ページ・Xには出さない。翌朝の答え合わせ(`results` の `are`、`summary.json` の `total.are`)で、公開後の新しいレースで確かめる。目安は半年(約550レース)。
- 次に試すなら: スタート展示のST(紙の上の記録がたまってから)、締切前のオッズとの比較(odds_paper)。混戦のレースで市場がどれだけ外枠を買いすぎているかは、オッズが無いと測れない。

### 2号艇(1号艇の隣)のF持ち(2026-10-29、`exp_are.main_fadj` → `experiments/are_fadj.json`)

「2号艇に今期のF持ちがいると1号艇が逃げにくい」を、exp_are と同じ52週の学習外で朝のモデルの見積もりと比べた(実際の1号艇の1着率 − 朝のモデル、[ ]は95%区間)。2号艇にFあり: 選ぶ期間 2,887レースで 53.3% − 54.4% = −1.1pt [−2.8, +0.6]、確かめる期間 3,777レースで 53.2% − 55.1% = −1.9pt [−3.4, −0.5]。Fなしは +1.4pt / +0.1pt なので、Fありはどちらの期間も約2ポイント低めに出ている。ただし選ぶ期間では区間が0をまたぎ、参考に見た3号艇のF持ちも確かめる期間で −1.5pt [−3.1, +0.0] と同じくらい下がる(隣だけの効果とは言い切れない)。2号艇のF2本以上は110レースで −9.2pt [−17.6, −0.4] だが数が少ない。万舟率は 17.1%(全体 16.2%)とほぼ同じ。決めておいた基準(両方の期間で区間の上端が0未満)に届かないので **見落としとは判定しない**。荒れ予報では「2号艇がF持ち(今期F数・選手名)」を事実として理由に並べるだけにし(優先度は低め)、荒れ度や確率は変えない。`are.py` はこのファイルの `missed` を毎朝読むので、学習し直して再検証し基準を満たしたら、自動で「検証ではAIの見立てより○ポイント低い」と書く強い理由に切り替わる。

## 結果: 自信ありレースの2着・3着と券種ごとの回収率、荒れるレースの確率の作り直し(2026-10-30 オーナー指示、`exp_place.py` → `experiments/place_v1.json`)

きっかけ(オーナー): 「1号艇の単勝は当たっても1倍で誰も買わない。1号艇が強いレースの勝負は2着・3着。1-2-3・1-3-2 のように1号艇を頭にして2・3着を当てる確率を上げたい。荒れるレースの高配当も。報告は的中数だけでなく券種ごとの最終オッズ・払戻・回収率まで」。

方法: exp_v4 と同じ52週のウォークフォワード(1着の確率はその週より前の365日で学習)。2着・3着の条件付きモデルは13週ごとにその時点より前の365日で学習し直す(本番は毎週なので控えめ寄り)。選ぶ期間 2025-10-31〜2026-04-30(27,179レース)、確かめる期間 2026-05-01〜10-29(28,277レース)。2着・3着の候補は選ぶ期間で1つずつ足し、2着+3着の対数損失の差の95%区間の上端が0未満なら残す。払戻は確定払戻(2連複・3連複も、選ぶ期間の分を K ファイルから上限つきで取り直した)。「自信度S」= 朝の1号艇の1着確率が67.6%以上で1号艇が本命(1日約48レース)、「自信あり上位5」= 1日の◎の確率の上位5レース(ページと同じ)。

### 本番への組み込み(2026-10-30)

- 毎朝の予想の2着・3着: 上の「採用」の朝の候補を `model_config.json` の `cond` に入れた(3連単の確率の当たり具合が良くなる。的中率の差ははっきりしない)。直前版(紙の上の検証だけ)も展示・進入を足した構成に。
- 予想ファイルに 2連複の上位3点(`quinella`)と、1号艇が本命のレースの「1号艇を頭にした2着・3着」の買い目(`head1`)を公開時に書き、翌朝に全部答え合わせする(2026-10-31〜)。上の検証で100%を超えると言えないので、ページには出さず記録だけ(`place_config.json`)。
- 毎日の答え合わせを券種ごとに(`report.py`): 全レース・自信あり上位5・荒れ予報TOP3のそれぞれで、単勝・2連単・2連複・3連単・3連複の 的中/買った数・払戻の合計・平均の倍率・回収率、的中レースの確定オッズ。summary.json・トップの前日の結果・Xの文面(`site_data.json` の `texts.x`)・本部の報告用(`texts.hq`)が同じ数字を使う。
